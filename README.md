# openadkit-e2e

L2 closed-loop end-to-end autonomous driving simulation.

Integrates [VisionPilot](https://github.com/autowarefoundation/autoware_vision_pilot), [Open AD Kit](https://github.com/autowarefoundation/openadkit), [Autoware Safety Island](https://github.com/autowarefoundation/autoware-safety-island), and CARLA.

This repository is the integration layer. Upstream changes belong in forks of those projects and are contributed back via pull request.
